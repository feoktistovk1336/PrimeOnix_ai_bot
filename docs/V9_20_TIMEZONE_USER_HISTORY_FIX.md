# PrimeOnix AI Bot v9.20 — Timezone + User History + Queue Planning Fix

Сделано поверх v9.19.

## Исправлено

- Добавлен единый часовой пояс планировщика через `APP_TIMEZONE`.
- По умолчанию используется `Europe/Moscow`, чтобы отложенная публикация выходила в указанное пользователем время, а не с UTC-смещением.
- Очередь и worker сравнивают `scheduled_at` в одном локальном времени.
- Примеры дат в очереди стали динамическими: `сегодня`, `завтра`, текущая дата в формате `ДД.ММ.ГГГГ`.
- Исправлена кнопка `📜 История пользователя`: теперь она входит в реальные админские действия, принимает user_id или username и показывает данные пользователя, очередь, обучение стилю и последние действия.
- Альбомы в очереди не отправляют промежуточные подтверждения на каждое фото: одно Telegram-альбомное сообщение = один материал = одно итоговое подтверждение.

## Railway

Рекомендуемая переменная:

```env
APP_TIMEZONE=Europe/Moscow
```

Если пользователь хочет другой часовой пояс, можно указать, например:

```env
APP_TIMEZONE=Europe/Stockholm
```

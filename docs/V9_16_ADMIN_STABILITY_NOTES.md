# PrimeOnix v9.16 — Admin Stability 10/10

Сделано поверх v9.15.

## Исправлено
- Админ-меню приведено к нужному порядку.
- Очередь: добавлена понятная структура управления материалами.
- Очередь: несколько фото в одном Telegram-альбоме теперь сохраняются как один материал, а не как несколько постов.
- Очередь: просмотр показывает тип медиа и количество фото в альбоме.
- Очередь: дата публикации редактируется через `ID завтра 18:00` или `ID 08.06.2026 18:00`.
- Кнопки очереди, рассылок, пользователей и статистики остаются внутри своих разделов.
- Добавлен безопасный переключатель разделов: если админ нажал другую кнопку во время ожидания ввода, бот переключает раздел, а не ломает сценарий.
- Статистика Telegram/Instagram отвечает базовыми данными из БД и очереди без старых заглушек.
- Python-синтаксис проверен.

## Не трогали
- Реальную генерацию mp4 Reels.
- Реальную автопубликацию Instagram через Meta/браузер.
